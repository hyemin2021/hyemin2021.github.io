# hyemin2021.github.io

[문제별 랩 타이머](https://hyemin2021.github.io/lap-timer/) 안드로이드 앱(TWA)의 도메인 확인용 저장소입니다.

- `.well-known/assetlinks.json`: 앱(`io.github.hyemin2021.laptimer`)과 이 사이트가 같은 주인임을 안드로이드에 알려 준다.
  이 파일이 있어야 앱 위쪽에 주소창이 뜨지 않는다.
- `.nojekyll`: GitHub Pages 가 `.well-known` 처럼 점으로 시작하는 폴더를 숨기지 않게 한다.
